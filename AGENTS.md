# Project instructions

## UI theme

Visual changes must follow `@src/theme.css` and `.cursor/rules/site-theme.mdc`.

- Use existing CSS variables and classes (`.section`, `.prose`, `.display`, `.headline`, `.lede`, `.btn`, `.rise-in`).
- Do not hard-code colors, type, or spacing when a token exists.
- Keep plain CSS; do not add Tailwind or a component library.
- Add new tokens to `src/theme.css` before using new values.
